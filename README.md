# Словарь — личный тренажёр английского

Бесплатное офлайн-приложение на Godot 4 для своих слов и фраз: из игр, фильмов, книг и переписки.
Без регистрации, рекламы и интернета. Всё хранится в одном JSON-файле на вашем компьютере.

## Запуск
1. Установите Godot 4.4 или новее (проверено на 4.7), обычная версия, не .NET.
2. В Godot: **Import** → выберите `project.godot` в этой папке → **Import & Edit**.
3. Нажмите **F5** (▶ Run Project).

Как сделать `.exe`: *Project → Export → Add… → Windows Desktop*. Если Godot попросит шаблоны экспорта,
нажмите *Manage Export Templates → Download*, затем *Export Project*.

## Что умеет
- **Категории.** Карточки с названием, числом записей и долей выученного. В меню «⋯» есть «Переименовать» и «Удалить».
- **Записи.** Каждая запись — английский, перевод и необязательная заметка. Записи можно изменить, копировать, дублировать, переместить в другую категорию или удалить. Есть поиск по обоим языкам.
- **Быстрое добавление в категории.** Впишите английский → Enter → перевод → Enter, и запись сохранена.
  Если вставить строку `phrase — перевод` или `phrase<Tab>перевод`, она сама разложится по двум полям.
- **Из буфера обмена.** Скопируйте фразу где угодно (Ctrl+C) и вернитесь в окно словаря: сверху появится
  «В буфере: …» с кнопкой «Добавить». Ещё вариант — **Ctrl+N** в любом месте: откроется окно добавления,
  английский уже вставлен, курсор стоит в поле перевода.
- **Пять режимов занятий:**
  - *Английский → русский* и *Русский → английский*: Пробел показывает ответ, дальше 1 — не знаю, 2 — почти, 3 — знаю.
  - *Ввод ответа*: Enter проверяет, ещё Enter — дальше. Регистр, лишние пробелы, знаки препинания,
    вид апострофа (don't / don’t / dont) и дефис не важны. Одна опечатка в длинном слове засчитывается
    как «почти». Другое слово, пропущенное или лишнее слово — ошибка, неверные слова подсвечиваются.
    Если подходит несколько вариантов, запишите их через ` / ` или `;`, например `big / large`.
    Кнопка «Засчитать как верный» — на случай, когда ваш вариант тоже правильный.
  - *Выбор из вариантов*: английский и пять переводов (верный + похожие из той же категории, если не хватает —
    из всего словаря). Клавиши 1–5 или щелчок. Верно — дальше само, ошибка — подсветка и Enter.
  - *Свободное повторение*: Пробел или щелчок переворачивают карточку, ← → листают. Без оценок, прогресс не меняется.
- **Настройка занятия.** Можно выбрать одну, несколько категорий или весь словарь, а также сколько карточек
  (10 / 20 / 30 / все). Флажки: «перемешать», «только сложные», «только к повторению сегодня».
  Выбор запоминается. Кнопка «Учить» в категории сразу открывает настройку с этой категорией.
- **Повторение по интервалам.** У каждой записи хранятся:
  - число верных, «почти» и неверных ответов;
  - дата последнего повторения;
  - уровень 0–6;
  - дата следующего повторения (через 0 / 1 / 3 / 7 / 14 / 30 / 60 дней).

  «Не знаю» возвращает карточку через пару других в том же занятии, а на следующих занятиях она выпадает чаще.
- **Главный экран.**
  - Блок «Сегодня: N карточек · ~M мин» с одной кнопкой «Начать» и полосой «сделано сегодня».
  - Тихие ссылки: настроить занятие, сложные слова, новая запись.
  - Поле «Найти или добавить фразу» (Ctrl+F) ищет по всему словарю. Если фразы нет, предлагает её добавить (Enter).
- **Категории.** У каждой свой цвет (меню «⋯» → «Цвет…») и кружок с числом карточек к повторению.
- **Занятие.**
  - Карточка лежит стопкой и переворачивается, когда показываешь ответ.
  - После оценки улетает: «знаю» — вправо, «не знаю» — влево, «почти» — вниз.
  - На кнопках подписаны клавиши.
  - Итог пишет по-человечески: сколько фраз за сколько минут и когда приложение напомнит о них снова.
- **Список записей.**
  - Вид «Компактно» — каждая запись в одну строку.
  - При наведении на запись появляются ✎ и ✕.
  - Удаление без лишних вопросов: внизу 6 секунд держится «Удалено · Вернуть». Так же можно вернуть удалённую категорию.
- **Строка «В буфере»** появляется внизу окна.
- **Тема** переключается значком ☾ / ☀.
- **Масштаб интерфейса:** 90–130 %, меню «Словарь ▾» или Ctrl+= / Ctrl+- / Ctrl+0.
- **Окно** запоминает размер и положение.

## Anki
**Из Anki в словарь.** «Словарь ▾ → Импорт из Anki (.apkg)…». Подходят экспорты Anki и Lookupper.
- Колода с фразами (Lookupper): при импорте выберите, что записывать. Выбор запоминается.
  - **Фразу целиком** — вся фраза из игры и её перевод, а слово с переводом идёт в заметку. Это вариант по умолчанию. Фразу читает голос системы.
  - **Только слово** — фраза показывается подсказкой под ответом.
- Из Lookupper также берутся транскрипция, определение, произношение слова (mp3) и скриншот.
- Из обычных колод берутся лицо и оборот. Звук и картинки — если есть.
- Каждая колода становится категорией.

**Синхронизация.** Экспортируйте колоду из Anki или Lookupper заново, затем «Словарь ▾ → Обновить из Anki». Приложение само возьмёт самый новый .apkg из той же папки:
- новые карточки добавятся;
- изменённые в Anki обновятся;
- прогресс и ваши правки нетронутых в Anki записей сохранятся;
- повторов не будет.

**Новый формат Anki** (только `collection.anki21b`) прочитать нельзя. При экспорте отметьте «Поддержка старых версий Anki».

**Из словаря в Anki.** «Словарь ▾ → Экспорт для Anki (.txt)…» сохраняет файл. В Anki откройте «Файл → Импорт» и выберите тип «Basic».

## Озвучка
- Кнопка 🔊 есть у каждой записи, в поиске и на карточке занятия.
- Если у записи есть произношение из Anki, звучит оно. Иначе английский читает **встроенный голос Piper**: нейросетевой американский голос, работает без интернета и без голосов Windows. Готовые фразы сохраняются в кэш, поэтому повторно звучат мгновенно. Следующие карточки занятия готовятся заранее.
- Если встроенный голос выключить («Словарь ▾ → Озвучка…»), читает голос Windows.
- На занятиях английский озвучивается сам. Отключить можно на экране «Новое занятие» или в «Словарь ▾ → Озвучка…».
- В режимах «Русский → английский» и «Ввод ответа» озвучка звучит только после ответа, чтобы не подсказывать.
- «▶ Прослушать» в категории читает записи по очереди: английский, затем перевод, если есть русский голос. Звучащая запись подсвечивается.
- «Словарь ▾ → Озвучка…» — выбор голосов, скорость, проверка.

### Встроенный голос — где лежит
Папка `voice/`: программа Piper (`piper/piper.exe`, английские словари espeak) и модель голоса `en-us-lessac-medium.onnx`, всего ~80 МБ.
- В редакторе Godot голос берётся прямо из проекта.
- В собранной `.exe` скопируйте папку `voice` рядом с exe — Godot её не упаковывает: в ней лежит `.gdignore`.

Голос Lessac обучен на наборе Blizzard 2013 (см. `voice/MODEL_CARD.txt`). Его лицензия рассчитана на некоммерческое использование: для личного словаря подходит, для продажи приложения голос нужно заменить.

Для тестов в Linux: `tools/get_piper_linux.sh` (кладёт `voice/piper-linux`, в git не входит).

## Где лежат данные
Меню «Словарь ▾» → «Открыть папку с данными». Обычно это:
- Windows: `%APPDATA%\EnglishTrainer\`
- Linux: `~/.local/share/EnglishTrainer/`
- macOS: `~/Library/Application Support/EnglishTrainer/`

`dictionary.json` — весь словарь. В папке `media` лежат звуки и картинки из Anki. Он сохраняется сам после каждого изменения. Запись идёт через временный файл,
поэтому сбой посреди сохранения не испортит словарь. В папке `backups` лежат автокопии: одна в день,
хранятся последние 10. Там же копии, которые делаются перед импортом и перед удалением категории.
Если `dictionary.json` повреждён, приложение не перезапишет его, а отложит копию `dictionary.broken-….json`.

## Экспорт и импорт
Меню «Словарь ▾» → «Экспорт в файл…» сохраняет весь словарь вместе с прогрессом.

«Импорт из файла…» ничего не удаляет и не перезаписывает:
- категории с тем же названием дополняются, остальные создаются;
- повторы (тот же английский и перевод) пропускаются;
- перед импортом делается резервная копия.

Кроме своего формата понимает простой список:
```json
[
  {"category": "Games", "en": "Press any key", "ru": "Нажмите любую клавишу", "note": ""},
  {"category": "Movies", "en": "I'll be back", "ru": "Я вернусь"}
]
```

## Устройство проекта
```
scenes/main.tscn                 главный узел: смена экранов, окна, сообщения, буфер обмена (scripts/main.gd)
scenes/screens/*.tscn            экраны: home, category, study_setup, study (scripts/screens/)
scripts/core/store.gd            Store — хранение, сохранение, копии, экспорт/импорт (автозагрузка)
scripts/core/srs.gd              интервальное повторение
scripts/core/answer_check.gd     проверка введённого ответа
scripts/core/session.gd          набор карточек для занятия
scripts/core/speech.gd           Speech — озвучка: звук из Anki или голос системы (автозагрузка)
scripts/core/anki_import.gd      колоды Anki: чтение, импорт/синхронизация, экспорт .txt
scripts/core/sqlite_reader.gd    чтение SQLite без библиотек (коллекция Anki)
scripts/core/dates.gd            даты и склонение «1 запись / 2 записи / 5 записей»
scripts/ui/app_theme.gd          AppTheme — светлая и тёмная тема (автозагрузка)
scripts/ui/*.gd                  компоненты: Screen, Page, Modal, Dialogs, EntryDialog, CategoryCard, EntryRow, Mastery, UI
tests/test_all.tscn              тесты логики и проход по всем экранам
tests/fixtures/*.apkg            тестовые колоды (tools/fixtures/make_apkg.py)
tools/check.sh                   сборка + тесты (--shots — снимки экранов)
```
